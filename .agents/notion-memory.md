# Notion Agent 记忆

用途：记录常用 Notion 页面、数据库、数据源、搜索入口和字段含义，避免每次全库搜索。这里只存索引和操作提示，不存密钥、token、cookie 或大段 Notion 正文。

## 使用规则

- 每次 Notion 任务前，先读本文件。
- 命中页面或数据库后，直接 `fetch/query`，不要重新全局搜索。
- 未命中时再用 MCP/`ntn` 搜索；找到稳定入口后补回本文件。
- 数据库首次使用后记录 schema 摘要、关键字段、常用过滤条件。
- 页面改名、数据库迁移、权限失效时更新或标记失效。
